# PxS (IRIS PxS)

Windows 11 専用の Epson GT-X820 フラットベッドスキャナー向けフィルムスキャンソフトウェア（業務用システム）。

## 主な機能
- **PreScan / Scan (最大 12800 DPI)**: 透過原稿ユニット (TPU) を制御し、高速予備スキャンおよび高解像度本スキャンを実行
- **赤外線ゴミ・キズ除去 (Digital ICE)**: 赤外線 (IR) スキャンによる欠陥マスク抽出と OpenCV インペインティングによる自動修復
- **フィルムフォーマット選択**: 35mm (フル / ハーフ / パノラマ)、中判 120 (6x4.5, 6x6, 6x7, 6x9) の自動コマ認識
- **ベースカラー自動検知 & NP変換**: フィルムの未露光オレンジマスク色を自動検知・補正、銘柄別プロファイル（Kodak Portra, Gold, UltraMax, Fuji Pro 400H, Superia, CineStill 800T, B&W等）
- **ロール管理 & Exifメタデータ個別入力**: スキャン画像を一時ストリップとして保持し、各コマごとにF値、シャッター速度、焦点距離、露出補正、メモを入力可能
- **一括エクスポート**: フィルム1本まるまるスキャン完了後、Exifメタデータを埋め込んでフォルダまたはZIPアーカイブとして一括書き出し（コンタクトシート・サマリー表同時生成）

## 開発環境 & 動作要件
- OS: Windows 11
- ランタイム: .NET 10 (WPF)
- ハードウェア: EPSON GT-X820 (WIA 2.0 / TPU)

## 起動方法
`run.bat` を実行するか、以下のコマンドを実行します:
```powershell
dotnet run -c Release
```
